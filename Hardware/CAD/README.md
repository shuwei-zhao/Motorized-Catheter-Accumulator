# CAD Files

This directory contains native CAD source files for the motorized catheter accumulator research prototype. The models should be reviewed against the as-built hardware before manufacturing replacements.

| File | Format | Intended role |
| --- | --- | --- |
| `MGN12H_Carriage_Adapter.f3d` | Autodesk Fusion archive | Connects the pulley assembly and lead-screw nut to the MGN12H carriage |
| `Guide_Pulley_120mm.f3d` | Autodesk Fusion archive | Large catheter-routing pulley |
| `Linear_Rail_Base_Platform.SLDPRT` | SOLIDWORKS part | Base platform beneath the linear rail |
| `Fixed_Catheter_Clamp.f3d` | Autodesk Fusion archive | Fixed catheter clamp component |
| `Ecoflex_Pad_Mold_Top.f3d` | Autodesk Fusion archive | Upper part of the compliant pad mold or fixture |
| `Ecoflex_Pad_Mold_Bottom.f3d` | Autodesk Fusion archive | Lower part of the compliant pad mold |

The repository currently contains the available native CAD sources only. Mesh exports, neutral STEP files, manufacturing drawings, and verified print settings are not yet included.
